About

This project is a Java application focused on Object-Oriented Programming (OOP) concepts using a movie management system as the main theme.
The structure was designed to be reusable and adaptable for different types of projects, such as games, books, inventory systems, or any data-driven application.

Features
Object-Oriented architecture
Reusable interface structure
Encapsulation, inheritance, and polymorphism
Simple and scalable code organization
Easy adaptation for new project themes

Java
IntelliJ IDEA
